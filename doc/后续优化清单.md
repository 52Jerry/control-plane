# NiuSu Control 后续优化清单

## 安全与账号体系

- 增加登录限流、连续失败锁定、验证码或二次认证。
- 增加 CSRF Token，并复核反向代理下的 Origin/Host 策略。
- 引入 RBAC，区分只读、节点运维、用户开通和系统管理员。
- 增加登录、导入、复制、重试、删除的安全审计，但审计内容不得包含密码或完整连接。
- 为管理会话增加服务端撤销列表、主动踢下线和设备会话管理。
- 设计 `CONTROL_PLANE_ENCRYPTION_KEY` 与 Node Manager Token/连接密文的在线轮换流程。
- 逐步停用兼容的 `X-Control-Token`，或改为有作用域和过期时间的服务账号令牌。

## 批量处理

- 大批次改为异步任务，提供进度、暂停、取消和结果下载。
- 支持 CSV/XLSX 文件导入并提供导入模板，服务端仍执行相同校验。
- 支持用户确认后仅重试失败行，避免重复提交有效行。
- 提供批次级回滚或补偿删除，并明确远端成功、控制面失败时的状态恢复规则。
- 增加重复 SOCKS、重复序号、重复用户的预检查和去重策略。
- 支持 IPv6、IPv6 URI 方括号和更完整的国际化域名测试。
- 增加可配置批次上限、并发度、Node Manager 限流和熔断。
- 支持自定义用户 ID 模板，并在提交前预览最终用户 ID。

## 可用性与可观测性

- 批量结果增加错误类型筛选、成功/失败导出和安全的一次性下载。
- 对敏感连接使用短时一次性查看令牌，减少长时间停留在浏览器内存。
- 增加 Node Manager 开通耗时、失败率、重试次数和容量水位指标。
- 为远端调用增加结构化错误码，前端按错误码展示稳定文案，避免依赖异常原文。
- 增加 Playwright 端到端测试，覆盖登录、粘贴、部分失败、复制和退出清理。
- 增加数据库迁移工具（Flyway/Liquibase），替代生产环境依赖 `ddl-auto=update`。

## 运维

- 提供账号初始化/离线恢复 CLI 或一次性引导页，避免人工编辑数据库并处理全部账号密码遗失场景。
- 增加密钥、账号密码和注册令牌的定期轮换手册。
- 为数据库密文备份、恢复和跨环境迁移建立演练流程。
- 在 CI 中执行前端构建、后端测试、Node Manager 测试、依赖漏洞扫描和敏感信息扫描。
- 为一次性安装码增加管理员撤销、生成记录查询和不含秘密的审计事件。
- 使用 Flyway/Liquibase 显式管理 `node_install_tokens` 等生产表结构，停止依赖 Hibernate 自动升级。
